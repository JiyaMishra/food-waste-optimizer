# Implementation status

This repository is a **starter implementation**, not a claim that every acceptance criterion is
already satisfied. The initial version includes synthetic CSV generation, starter menu data,
validation, availability calculation, feature engineering, forecasting, evaluation, tests and
handover documentation.

Before submission, expand tests for foreign keys and all table relationships; verify the menu names
against the original menu photos; test same-seed reproducibility; inspect leakage across every
feature; and run the full pipeline from a clean checkout. The initial synthetic menu catalogue is
illustrative and should be manually checked against the supplied vegetarian menu images.
