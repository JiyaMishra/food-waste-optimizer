# Data dictionary (Person A starter)

All CSVs under `data/generated/` are synthetic. Every generated dataset carries
`is_synthetic`, `generation_seed`, `generated_at`, `scenario_id`, and `dataset_version`.

| File | Grain | Important fields | Notes |
|---|---|---|---|
| `residents_synthetic.csv` | One pseudonymous synthetic resident | `resident_key`, `hostel_id`, `mess_id`, `cohort` | No real names or registration numbers |
| `hostel_daily_state.csv` | Date × synthetic hostel | `capacity`, `occupied_count`, `occupancy_rate` | Occupancy cannot exceed capacity |
| `academic_slots.csv` | Date × synthetic cohort slot | `activity_type`, `start_time`, `end_time` | Illustrative timetable only |
| `campus_events.csv` | One simulated event | `event_id`, `date`, `expected_participants` | May be empty if no event is generated |
| `weather_daily.csv` | One simulated date | `rain_mm`, `temperature_c`, `source_type` | No live weather feed |
| `menu_calendar.csv` | Meal × dish × date | `meal_id`, `dish_id`, `dish_name` | Seeded vegetarian menu |
| `preference_survey_synthetic.csv` | Synthetic respondent × dish | `respondent_key`, `dish_id`, `rating` | Not a real survey |
| `meal_attendance.csv` | Meal × 30-minute interval | `arrivals`, `cumulative_attendance` | Interval arrivals reconcile to meal total |
| `food_operations.csv` | Meal × dish | `prepared_qty`, `served_qty`, `consumed_qty`, `untouched_leftover`, `plate_waste` | Unit is portions |
| `evaluation_report.json` | One evaluation run | train/test periods, MAE/RMSE | Generated by evaluation script |

## Accounting
`untouched_leftover = prepared_qty - served_qty`; `plate_waste = served_qty - consumed_qty`.
These are tracked separately. Do not add plate waste to leftovers without defining a distinct
total-waste formula that avoids double counting.
